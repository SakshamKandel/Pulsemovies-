# Pulse Movies 🎬

A modern, cinematic movie & TV streaming web application built with Next.js App Router, Tailwind CSS, TMDB API, and optimized for deployment on Cloudflare Workers & Pages via OpenNext.

## 🚀 Quick Start

### Local Development
```bash
cd movie-app
npm install
npm run dev
```

### Production Build
```bash
cd movie-app
npm run build
```

### Cloudflare Deployment
See [movie-app/DEPLOY.md](movie-app/DEPLOY.md) for complete instructions.
```bash
cd movie-app
npx wrangler login
npm run deploy:cf
```
